O **Rimufic** é um gerador de prompts detalhados e focados em narrativas para fanfics. Construído puramente com HTML, CSS e JavaScript (Vanilla), ele ajuda escritores a estruturarem instruções cinematográficas para IAs, garantindo que a história seja desenvolvida no ritmo certo e respeite a essência dos personagens.

## 🚀 Funcionalidades

* **Personalização Completa:** Defina o Fandom, Personagem A e Personagem B.
* **Tropos Literários:** Escolha entre Enemies to Lovers, Friends to Lovers, Proximidade Forçada, Identidade Secreta ou Rivais. Cada tropo gera fases de desenvolvimento únicas.
* **Clima/Vibe:** Ajuste o tom da narrativa (Slowburn, Angst, Fluff, Dark).
* **Comando de Paginação Automático:** O prompt gerado já inclui uma instrução nativa ensinando a IA a usar o comando `"próxima página"`, permitindo que você escreva capítulos longos sem perder o contexto, fazendo a IA entender que é para continuar escrevendo uma nova parte.
* **Interface Moderna:** Design responsivo, tema escuro com cores vibrantes e integração com ícones FontAwesome.
* **One-Click Copy:** Botão para copiar facilmente o prompt gerado.

## 🛠️ Como Usar

1. Acesse a página do projeto ou abra o arquivo `index.html` no seu navegador.
2. Preencha os campos com os detalhes da sua história (Fandom, Personagens, etc.).
3. Escolha o Tropo (Dinâmica do casal) e a Vibe (Tom da história).
4. Adicione um evento inicial (Gancho) e detalhes específicos opcionais.
5. Clique em **"Gerar Prompt Detalhado"**.
6. Clique no botão **"Copiar Prompt"** e cole na sua IA de preferência (ChatGPT, Gemini, Claude, etc.).
7. Quando a IA terminar de gerar a primeira parte, basta digitar **"próxima página"** para que ela continue a história de onde parou.

## 💻 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização, Flexbox, Grid, Animações e Glassmorphism.
* **JavaScript (Vanilla):** Lógica de geração do texto estruturado e funcionalidade de copiar.
* **FontAwesome:** Ícones na interface de usuário.
